## 1. 设计思路

主角是 **Moko**，一朵从角落探出头的云。图标和应用里是同一个构图、同一条轮廓，来自 `assets/icon.svg`。

思路来自设计师枯白啃（[@Kubai087](https://x.com/Kubai087/status/2116744536034824457)）讲 Icon 的三条，加上他的[“降低非必要体积”](https://x.com/Kubai087/status/2115674219602452656)：

| 原则 | 在 Moko 上怎么做 |
|---|---|
| 主体负责拟人，画布负责产品功能 | Moko 只有表情；风线、灰尘点、星星都画在天空上，水滴是配饰（加湿） |
| 对比度拉大 | 白云配高饱和纯色 |
| 倾斜裁剪，只探出头 | 倾斜 15°，从右下角探出，被卡片边缘裁掉。脸大，小尺寸也认得出 |
| 高饱和色不做上亮下暗的渐变 | 天空全部用纯色 |
| 阴影不掺黑 | 眼睛和投影用天空同色相的深色 |

| 状态 | 天空 | Moko | 画布 |
|---|---|---|---|
| PM2.5 ≤12 | 钴蓝 | 开口笑 | 风线 |
| ≤35 | 青绿 | 微笑 | 风线 |
| ≤55 | 奶黄（深色文字） | 平嘴 | 风线 |
| ≤150 | 橙 | 担心，变灰 | 风线、灰尘 |
| >150 | 红 | 更担心，更灰 | 风线、灰尘 |
| 关机、夜间模式 | 深蓝夜空 | 闭眼，飘 z | 星星 |
| 没有读数 | 灰 | 淡淡微笑 | 风线 |
| 加湿中 / 缺水 | 不变 | 水滴飘在头上 / 水滴变空心，表情担心 | 不变 |

天空的颜色和画布都有含义，所以别的卡片不借用它们：

| 卡片 | 颜色 | 画布 | 动画 |
|---|---|---|---|
| Apple 家庭（已加入） | 暖橙，取自“家庭”App | 一栋房子，Moko 从门边探头 | 窗户的灯慢慢亮灭 |
| 设置的设备卡（已连接） | 绿 | 围着 Moko 的信号圈 | 一道波向外传 |
| 设置的设备卡（搜索中、已断开） | 灰 | 信号圈 | 搜索时有波；断开时静止，Moko 担心 |

档位和 Apple 家庭一致（12/35/55/150）。风线的流速跟风量走：静音和夜间慢，强档快。

## 2. 主窗口（1040×700）

```
┌───────┬───────────────────────┬────────────┐
│ Moko  │ 空气很清新            │ ⏻ 运行中 ▣ │
│       │ ⌂ 室内 25°C 49%       │ 四格图标   │
│ 概览  │ ☾ 室外 11°C 93% 风线  │ 加文字     │
│ 天气  │                       │ 共两行     │
│ 趋势  │ 0          ╭ Moko     │ ────────   │
│ 能耗  │ PM2.5      │ • •      │ 💧 加湿  ▣ │
│ 家庭  ├───────────────────────┴────────────┤
│ 设置  │ PM2.5    湿度    室温    功率·今日 │
│       │ 0        51%     24°C    13 W      │
│       │ ━━━━━                              │
│       │ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ │
│ ● KI-… │ 21:00                        现在 │
└───────┴────────────────────────────────────┘
```

| 页面 | 内容 |
|---|---|
| 概览 | 上图。读数和图表切换是同一个控件：点哪个读数，就看它过去 24 小时。天空里两行室内外温湿度，数字对齐好比较；室外这行点击进入天气页，图标是当前天气 |
| 天气 | 现在、室内外对比、未来 24 小时、未来 3 天；地点和开关。数据来自 Open-Meteo |
| 趋势 | PM2.5、湿度、温度：24 小时 / 7 天 / 30 天；每日净化空气量 |
| 能耗 | 今日、本月、累计用电，电费，每日柱状图 |
| Apple 家庭 | 未配对时：开关、二维码和配对码、防火墙和权限引导。已配对时：天空卡片说明已加入、家庭里能用什么，下面一张卡放开关、防睡眠和解除配对 |
| 设置 | 左边是设备卡：天空和 Moko、设备信息、五项耗材剩余。右边是偏好：开机自启、外观、缺水通知、语言、电价、手动 IP，控件右对齐、同宽；下面是关于：版本和检查更新、作者和源码、退出 |

模式是一个控件、一个选中项：两行八格，每格图标加文字，钴蓝色在格子之间上下左右滑动。设备本来就只有一个模式。风量三档的图标从羽毛、风到龙卷风，一眼能看出强弱。

运行和加湿两行开头是同样的图标块，开着时带颜色。缺水时水滴换成划掉的水滴，转警告色。

## 3. 托盘面板（320×436）

日常操作都在这里完成：电源、空气和读数、模式、加湿。结构和主窗口相同，复用同样的部件。面板自己画背景，不用系统毛玻璃，保证对比度。

外观可以选自动、浅色、深色（`mygo.Theme.SetSource`，窗口框架也跟着变）。

托盘图标是有两只眼睛的云朵剪影（正面，不倾斜，18 px 下读不出倾斜），缺水或故障时多一个圆点。macOS 用 template 图标，Windows 按任务栏深浅切换黑白。Tooltip 显示当前读数。

## 4. 设计规范

### 颜色

纸和墨，加一个钴蓝。中性色用 H85 的极低彩度（暖灰），不带蓝色调。L/C/H 如下：

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| bg | 0.17 / 0.003 / 85 | 0.955 / 0.005 / 85 | 内容区底色 |
| side | 0.21 / 0.003 / 85 | 0.925 / 0.006 / 85 | 侧栏，和内容区之间一条细线 |
| card | 0.215 / 0.003 / 85 | 纯白 | 卡片 |
| card2 | 0.27 / 0.003 / 85 | 0.94 / 0.005 / 85 | 轨道 |
| text | 0.96 / 0.003 / 85 | 0.2 / 0.005 / 85 | 主文字 |
| muted | 0.74 / 0.004 / 85 | 0.46 / 0.006 / 85 | 次要文字 |
| faint | 0.66 / 0.004 / 85 | 0.52 / 0.006 / 85 | 辅助文字 |
| capsule | 同 text | 同 text | 选中项：墨色胶囊 |
| accent | 0.68 / 0.17 / 255 | 0.56 / 0.2 / 255 | 开关、PM2.5 曲线、柱状图 |
| water | 0.76 / 0.11 / 215 | 0.58 / 0.12 / 225 | 湿度曲线 |
| warm | 0.74 / 0.14 / 40 | 0.62 / 0.17 / 38 | 温度曲线 |
| power | 0.8 / 0.14 / 80 | 0.68 / 0.15 / 70 | 功率曲线 |
| ok / warn / bad | | | 在线、警告、错误 |

天空的值见 `internal/view/palette.go`。

对比度（WCAG，算出来的）：卡片和底色上的正文、辅助文字都不低于 4.5:1；每种天空上的文字都不低于 4.5:1（钴蓝 4.7，青绿 5.2，奶黄 9.9，橙约 4.6，红 5.8）。

### 字体

- **内嵌 Nunito**（`internal/view/fonts/`，OFL），圆润的字母和数字最配 Moko，增加约 280 KB。中文、日文由系统字体回退。
- 数字用 `FontFeatures("tnum")`，刷新时不跳动。
- 层级：主数字 100 / 800，读数 26 / 800，标题 15–20 / 700，正文 13，说明 11–12。
- 日文系统上中文可能回退到日文字形，用 `Lang` 指定语言。

### 形状与深度

卡片和天空 20，轨道 13，胶囊 10（13 − 3 的内距），模式格 12。macOS 上 MyGo 自动用连续圆角。每个面只有一种深度：卡片一条 1 px 细线，没有阴影。

### 控件对照

| 需求 | MyGo |
|---|---|
| Moko | `Draw` + `Painter`，`AnimationFrameRate(30)` |
| 天空的风线、灰尘、星星 | 画在天空元素自己的 `Draw` 里。放在上层的绝对定位元素会吃掉点击 |
| 走势 | `ui/chart` |
| 模式 | `ButtonBase` + `RoleRadio`，格子和滑动的选中色都在轨道的 `Draw` 里画。设备关机时没有选中项，`SegmentedBase` 不支持 |
| 读数切换 | `ButtonBase` + `RoleRadio`，下划线在行的 `Draw` 里画 |
| 电源、加湿 | `ui.Switch` |
| 导航 | `ButtonBase`，胶囊在列表的 `Draw` 里画，当前页存在 `View.Page` |
| 托盘面板 | `mygo.NewFlyout` |

**画路径要注意**：MyGo 按路径坐标的大小光栅化遮罩，再做变换，遮罩和文字共用一张图集。用大坐标配缩小变换，会撑爆图集，文字随之消失。所以路径坐标要换算到实际 DIP，只用变换做微小的移动和旋转，这样遮罩只画一次。

## 5. 状态比正常页面更重要

| 状态 | 表现 |
|---|---|
| 首次启动 | 自动搜索设备，显示活着的图标；找不到时给手动 IP 入口和排查提示 |
| 本地网络权限被拒（macOS） | 明确说明，一键打开系统设置 |
| 防火墙拦截（Windows） | 先显示说明卡片，一键放行（UAC），可跳过 |
| 设备离线 | 保留最后读数，顶部提示“x 分钟前”，控件禁用 |
| 关机 | 夜空，Moko 睡着，模式不高亮；选模式会开机 |
| 缺水 | 水滴变空心，加湿行转警告色，托盘图标加圆点，系统通知（可关闭） |
| 检测到污染 | 天空里多一行字；没有污染时不显示 |
| 空气变差 | 天空转色，Moko 的表情慢慢变化，灰尘飘起来 |
| 写入中 / 失败 | 控件先显示目标值；回读失败时退回真实状态并 Toast 提示 |
| 字段未知 | 显示 `—`，不要猜 |

## 6. 动效

| 什么 | 怎么动 | 时长 |
|---|---|---|
| 换模式、换页、切读数 | 选中色、胶囊或下划线滑到新位置（`AnimateTo` + 弹簧，微回弹） | 300 ms |
| 按下 | 缩到 0.96（`AnimatePose`，`ui.Snappy`） | — |
| 悬停 | 颜色过渡（`AnimateColor`） | 120–140 ms |
| 进入页面 | 上移 8 DIP 并淡入（`Transition`） | 240 ms |
| 读数变化 | 数字滚动（`ContentTransition{Numeric}`），变小时向下 | 350 ms |
| 切换图表内容 | 从左向右画出（首次显示不播放） | 600 ms |
| 空气变化 | 天空转色，Moko 的表情过渡 | 700–900 ms |
| Moko | 呼吸（节奏跟风量），偶尔眨眼，水滴轻轻浮动；被点击或设备状态变化时跳一下 | 持续 |
| 风线 | 一段亮线沿风线流动，速度跟风量 | 持续 |

原则：

- 开关的滑块 140 ms。它改变的东西要等它滑完：系统调用（开机启动会卡住主线程一秒多）和启停 Apple 家庭延后 220 ms，页面重新排版（天气、Apple 家庭）关闭时延后 180 ms、打开时延后 260 ms，否则滑块看起来是跳过去的。
- 只有 Moko 和天空持续在动，且只在 `Draw` 里动（只重绘，不重建视图），限 30 帧。其他静态卡片用 `Cache()`。
- 风线的亮段按固定步长移动，遮罩循环复用，不会每帧重画。
- 实测（Apple Silicon）：窗口打开时约 6.5% 个核，隐藏到托盘后约 0%。
- 系统开启“减弱动态效果”时，Moko 和天空静止，MyGo 的动画直接到终点。

## 7. 图标

`assets/icon.svg` 是源文件。`assets/AppIcon.icon` 是 Icon Composer 分层版本（风线、Moko、水滴三层，由 SVG 导出，macOS 26 起是 Liquid Glass 图标），`assets/icon.png` 用于旧版 macOS 和 Windows。托盘图标由 `TestAssets` 绘制。

DMG 的背景分两步：`TestAssets` 用应用自己的 Moko 画底图 `assets/dmg/background-source.png`，`scripts/make-dmg-background.swift` 加上标题和当箭头用的那道风，合成 1x、2x 的 `background.tiff`。
